صدى العراق — إصدار 1.6.33
دليل النشر والتنظيف الآمن
================================

محتويات التشغيل الأساسية في جذر المشروع:
- server.js: خادم الموقع ومسارات API.
- index.html: الواجهة.
- package.json وrailway.json: إعدادات تشغيل Railway.
- version.txt وBUILD_ID.txt: بصمة الإصدار التي يفحصها /api/health.
- bundled-assets.json وapi-addon.js وfirebase-messaging-sw.js: ملفات تستخدمها الواجهة أو الخادم.
- config.json وdatabase.rules.json: إعدادات مساعدة؛ احتفظ بها.

مهم جداً — كي يظهر التحديث فعلاً:
1) نزّل ZIP ثم فك ضغطه. لا ترفع ملف ZIP نفسه إلى مستودع GitHub على أنه تحديث للكود.
2) افتح جذر مستودع GitHub المرتبط بخدمة Railway. يجب أن تظهر ملفات index.html وserver.js وpackage.json وversion.txt مباشرةً في الجذر، لا داخل مجلد فرعي ولا بجانب مجلد يحتوي النسخة الجديدة.
3) استبدل الملفات التي تحمل الأسماء نفسها بنسخ الحزمة الجديدة، وأضف الملفات الجديدة المطلوبة. لا تحذف قاعدة Firebase ولا مجلد بيانات الإنتاج ولا أسرار البيئة.
4) افتح Railway > الخدمة الصحيحة > Settings وتأكد أن Root Directory فارغ إذا كانت الملفات في جذر المستودع. افحص أيضاً أن الخدمة مرتبطة بالمستودع والفرع الصحيحين.
5) بعد النشر افتح: /api/health?ts=وقت-جديد. يجب أن تكون version وuiVersion = 1.6.33، وأن تتطابق buildId وuiBuildId وversionFile وbuildFile، وأن تكون deploymentConsistent = true.
6) إذا بقي /api/health يعرض 1.6.29 أو 1.6.30، فهذه ليست الحزمة الجديدة التي تشغلها الخدمة: تحقق من المستودع/الفرع/Root Directory/الخدمة أو أن ملفات الجذر استبدلت فعلاً. لا تعتبره مجرد كاش للمتصفح. إذا عرض /api/health 1.6.33 لكن الصفحة قديمة، افتح الصفحة في نافذة خاصة أو امسح بيانات الموقع.

الأمان:
- لا ترفع .env أو firebase-service-account.json أو مفاتيح/كلمات مرور إلى GitHub.
- اترك FIREBASE_DATABASE_URL وFIREBASE_SERVICE_ACCOUNT_JSON أو FIREBASE_SERVICE_ACCOUNT_BASE64 والأسرار الأخرى في Railway Variables.
- لا تحذف مجلد البيانات الدائم ولا تغيّر Firebase Rules إلى قراءة/كتابة عامة.

اختبارات الإصدار:
- npm test يشغّل فحوص الإصدار وAPI وآسياسيل باستخدام بيئات محاكاة محلية.
- الاختبارات لا تنفّذ تحويلاً مالياً حقيقياً ولا تتصل بقاعدة Firebase الإنتاجية. بعد تأكيد الإصدار، اختبر الوظائف الحقيقية بحذر وعلى حساب/مبلغ اختبار.
