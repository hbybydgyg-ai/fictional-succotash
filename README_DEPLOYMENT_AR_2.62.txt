صدى العراق 2.62 — تشغيل وفحص النسخة

المتطلبات:
- Node.js 22 أو أحدث.
- متغيرات Firebase وصلاحيات الخادم المضبوطة في إعدادات الاستضافة.
- تعيين SESSION_SECRET ثابت وعشوائي بطول 32 حرفاً أو أكثر، أو استخدام إعدادات اعتماد الخادم الموثوقة كما هو موثق بالمشروع.

النشر على Railway:
1. نزّل ZIP وافتحه. ارفع محتوياته إلى جذر المشروع الحالي، بحيث يكون server.js وindex.html وpackage.json في جذر المشروع مباشرة، وليس داخل مجلد فرعي إضافي.
2. احتفظ بمتغيرات الاستضافة السرية الموجودة، ولا تضع التوكنات أو مفاتيح Firebase في الكود أو ترسلها بالمحادثات.
3. تأكد أن أمر التشغيل هو npm start وأن إصدار Node.js هو 22 أو أحدث.
4. بعد النشر افتح /api/health على عنوان موقعك. يجب أن تظهر deploymentConsistent بقيمة true، وأن تتطابق version وuiVersion مع 1.6.87.
5. شغّل npm test محلياً من جذر المشروع قبل النشر للتأكد من اجتياز الاختبارات.

مهم:
- نجاح الاختبارات المحلية لا يثبت اتصال قاعدة الإنتاج أو صلاحية مفاتيحها؛ تأكد من ظهور firebaseServerAuthConfigured بالقيمة true عند استخدام اعتماد خدمة Firebase من الخادم.
- لا تضع بيانات إنتاج حقيقية داخل مجلد data في نسخة عامة أو مشتركة.
- لم يتم نشر هذه النسخة نيابة عنك؛ تحتاج صلاحية إلى مشروع الاستضافة لإجراء النشر الفعلي.
