صدى العراق 2.7 — بطاقة سعر الصرف أسفل المحفظة ومراقبة نشاط API

- إزالة نافذة سعر الصرف المنبثقة عند فتح شحن الرصيد؛ عرض بطاقة صغيرة ضمن آخر محتوى صفحة المحفظة.
- إضافة عرض أنشطة مستخدم API: معلومات الحساب غير السرية، الرصيد، وعدد الطلبات وآخر 100 طلب مسجل.
- إضافة حظر ورفع حظر استخدام API لجميع مفاتيح المستخدم عبر سجل Firebase مركزي apiKeyBlocks، من دون حظر دخول الموقع أو حذف الحساب أو الطلبات.
- الحفاظ على انتهاء المفتاح الجديد غير المستخدم بعد 24 ساعة، وتفعيل العدّاد عند أول استخدام وفق السلوك الموجود.
- إضافة فحوصات ثابتة للمسارات الجديدة وبطاقة سعر الصرف، والحفاظ على تسجيل دخول المالك المضمّن.
